## Markdown in one minute

Markdown is a lightweight markup language that adds structure to plain text using readable punctuation. A Markdown processor renders that source into HTML or another output format.

```markdown
# Project title

A short **description**.

- Easy to read
- Easy to version
```

CommonMark defines a standardized core; GitHub Flavored Markdown adds common features such as tables, task lists and strikethrough.
