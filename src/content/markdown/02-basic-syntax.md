## Basic structure

```markdown
# Main title
## Section

A paragraph with **bold** and *italic* text.

Line one  
Line two
```

Use one to six hash characters for headings and separate paragraphs with a blank line. Two trailing spaces create a hard line break in CommonMark; line-break behavior can vary by renderer.
