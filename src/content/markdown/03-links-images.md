## Links and images

```markdown
[CommonMark](https://spec.commonmark.org/)

![A useful description](images/diagram.png)

[Reference link][docs]

[docs]: https://docs.github.com/en/get-started/writing-on-github
```

Use descriptive link text and meaningful image alt text. Relative image paths are usually resolved from the Markdown file, but publishing systems can differ.
